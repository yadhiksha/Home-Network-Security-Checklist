1. Executive Summary

A rigorous cybersecurity assessment was executed across a residential local area network (LAN) and wireless local area network (WLAN) infrastructure. The primary goal was to evaluate gateway edge security, wireless encryption ciphers, administrative credentials, network segmentation, and host endpoint hygiene against authoritative standards published by the Cybersecurity and Infrastructure Security Agency (CISA).

Residential networks now function as enterprise edge extensions due to pervasive telework. The proliferation of low-cost, unmanaged Internet of Things (IoT) peripherals combined with unhardened gateway routers presents an expanded attack surface for cyber adversaries seeking initial footholds.

2. Objectives, Scope & Rules of Engagement

This engagement was conducted under authorized ethical testing guidelines, targeting exclusively privately owned equipment.

  • Asset Visibility: Complete enumeration of all connected wired and wireless devices on subnet 192.168.1.0/24.
  • Perimeter Defense: Elimination of default credentials, deactivation of Universal Plug and Play (UPnP), and disabling remote WAN administration.
  • Wireless Hardening: Migration toward WPA3-Personal (SAE) with Protected Management Frames (PMF) and elimination of Wi-Fi Protected Setup (WPS).
  • Architectural Segmentation: Deployment of a segregated Guest Network for IoT peripherals with Client Isolation enforced.

4. Wi-Fi Security & Router Administration Audit

4.1 Wireless Cipher & WPS Evaluation

  • WPA2 vs WPA3: The baseline network utilized WPA2-Personal (AES-CCMP). While AES is robust, WPA2's 4-way handshake remains susceptible to offline dictionary cracking via hashcat if captured via de-authentication frames. The network must transition to WPA3-Personal (SAE) or WPA2/WPA3 Mixed Mode with Protected Management Frames (PMF / 802.11w) enforced.
  • Wi-Fi Protected Setup (WPS): WPS was identified as enabled in baseline testing. Because WPS PINs can be brute-forced in hours via Reaver/PixieWPS, WPS must be permanently DISABLED.
  • SSID Fingerprinting: Factory SSIDs revealing router hardware models were replaced with neutral identifiers.

4.2 Router Admin Access & UPnP

  • Default Credentials: Replaced default administrator passwords with a 20+ character Diceware secret stored in a password manager.
  • Remote Management: Remote Web Management over WAN was verified as DISABLED, eliminating exposure to public Internet botnets.
  • Universal Plug and Play (UPnP): UPnP was toggled to DISABLED to prevent compromised LAN devices from dynamically punching inbound firewall holes.

5. Router Firmware Lifecycle Assessment

Firmware Verification Policy
In accordance with audit requirements, no firmware update is claimed as installed until physically validated. The baseline assessment discovered firmware build v1.0.4 Build 20220315, which is 4 major revisions behind current vendor release v1.2.1 Build 20240918. Updating via wired Ethernet is strongly mandated.

6. Guest Network & Architectural Segmentation

A flat home network permits direct line-of-sight lateral movement between low-security IoT peripherals and high-value workstations. Enabling a dedicated Guest Network on the 2.4 GHz band with Client Isolation (AP Isolation) and "Block Access to LAN" restricts IoT devices to outbound Internet connectivity exclusively.

9. Primary Security Risk Deep-Dive

Critical Finding: Unsegmented Flat Network with Outdated Gateway Firmware
The most dangerous condition identified is the intersection of multi-year outdated router firmware and a flat, unsegmented network architecture. An external adversary exploiting a known public router CVE (e.g., CVE-2023-1389) or pivoting through an insecure IoT camera has unrestricted, line-of-sight access to execute ARP poisoning, SMB relay, and credential harvesting against telework workstations and banking endpoints.

11. Remaining Actions & Conclusion

  1. Immediate (24 Hours): Rotate Wi-Fi PSK to 20+ characters; enforce unique router admin password; disable WPS and UPnP.
  2. Short-Term (48-72 Hours): Verify exact hardware revision and flash latest vendor firmware over wired Ethernet; instantiate Guest Network and migrate IoT devices.
  3. Long-Term: Enforce BitLocker/FileVault full-disk encryption and establish 3-2-1 offsite backup pipeline.

Implementing these CISA-aligned controls transforms the residential network from an easily exploitable flat subnet into a resilient, defense-in-depth architecture capable of protecting modern telework and personal data.
